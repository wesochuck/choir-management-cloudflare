# Mobile Member workspace navigation concepts

Approved navigation direction, October 28, 2026. AI-generated concepts, not implemented screenshots or verification evidence.

Home opens existing Dashboard directly. Schedule opens My schedule directly. Practice opens a Practice & resources sheet with Practice and Resources. More opens Your membership with My Profile, Directory, Season dues. Use current module/access filtering and shared route metadata. Preserve desktop behavior and existing member capabilities.

Event cards, dates, venues, times, counts, RSVP wording, extra tabs, and page copy are illustrative and vary between generated images; preserve actual schedule/RSVP behavior.
