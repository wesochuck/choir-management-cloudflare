# Linked Rehearsal Attendance Confirms Performance RSVP

When an Organization Profile is recorded Present for a Rehearsal linked to a Performance, the system
will reconcile both the Rehearsal RSVP and its parent Performance RSVP to Yes. This matches the
product rule that rehearsal attendance is recorded only when the person is coming to the linked
Performance, while still allowing a person to RSVP No to a Performance without any rehearsal
attendance being recorded.
