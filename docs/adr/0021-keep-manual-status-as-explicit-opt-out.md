# Keep Manual Status as an Explicit Opt-Out

Choosing a Profile Status such as On Break will not automatically enable manual status management.
The separate manual control is the explicit opt-out from Profile Status Automation and the On Break
Timeout, allowing ordinary On Break Profiles to age toward Inactive while administrator Profiles can
be deliberately exempted. If the exemption is removed while a Profile remains On Break, the timeout
starts fresh rather than immediately counting the exempted period.
